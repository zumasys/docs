# Rover Web v2.37.0 Release Notes

<badge text="Version 2.37.0" vertical="middle" />

<PageHeader />

These are the release notes for version 2.37.0 (10/04/2026) of the Rover Web application and can be made available to customers running _Rover ERP_, _IMACS_ and other non-Zumasys owned systems. Contact your _Client Success Manager_, [Sales](mailto:sales@zumasys.com?subject=Rover%20Web%20v2.37.0) or [Support](mailto:help@zumasys.com?subject=Rover%20Web%20v2.37.0) today!

## New Features

### General

- Added an **Open Source Licenses** link to the application footer so users can review attribution and license information for the third-party software included with Rover Web.

### Document Processing

- Added support for submitting DWF design and plan files in addition to PDF files when sending documents for automated processing.
> Only supported by select subscriptions

## Improvements

### General

- Rover Web and Rover Portal now share a common set of components and utilities, so features such as attachments and sales order handling behave more consistently across both applications.

### Production

- Improved responsiveness of the Scheduling board when working with longer date ranges or a large number of operations.

## Bug Fixes

### Production

- Fixed an issue where the Scheduling board could freeze or stop responding when the selected date range spanned a daylight saving time change.

### Point of Sale

- Fixed an issue where opening a link directly to a mid-checkout page, such as Shipping, without an order in progress could cause the application to stop responding. Users are now returned to customer selection instead.
- Fixed potential errors on the Invoices, Sales Quotes, and Receipt History screens when no customer was selected.
