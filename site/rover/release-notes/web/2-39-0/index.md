# Rover Web v2.39.0 Release Notes

<badge text= "Version 2.39.0" vertical="middle" />

<PageHeader />

These are the release notes for version 2.39.0 (10/21/2026) of the Rover Web application and can be made available to customers running _Rover ERP_, _IMACS_ and other non-Zumasys owned systems. Contact your _Client Success Manager_, [Sales](mailto:sales@zumasys.com?subject=Rover%20Web%20v2.39.0) or [Support](mailto:help@zumasys.com?subject=Rover%20Web%20v2.39.0) today!

## New Features

### Production

- The Production Gantt chart label column now stays aligned with the chart rows by sharing a single scroll area, so labels and rows scroll together.
- The non-working day overlay now scrolls with the chart rows.

### Rover Portal

- Categories defined with a callout button now open in the shared category dialog in the Orders module.
- The category dialog can now show or hide the category key based on the parent category's **Show Category Key** setting.
